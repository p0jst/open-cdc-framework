# Roadmap

## v1.0.0 — released 2026-09-02 (current)
Core framework (six CSF 2.0 functions with CIA mapping, maturity criteria, EU hooks, external-dependency tables) · design layer (start-here prioritisation, E/S/A tiers, operating models incl. MSSP and shared CDCs, ECSF-based roles) · operations layer (tuning, detection-as-code + deep dive, CTI deep dive, automation guardrails, tool discipline) · community layer (RFC 2350, TF-CSIRT/FIRST, SIM3 crosswalk, controls register, annual calendar) · regulatory layer (EU landscape, 27 national annexes, interactive law selector, CIS Controls crosswalk) · practical assets (9 templates, 4 platform playbooks, design navigator, maturity self-assessment) · published website with three dependency-free browser tools (regulatory profile selector, team skill matrix, maturity self-assessment).
